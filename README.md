# Spaceo

Un petit logiciel Windows pour voir ce qui remplit ton disque :
espace libre, et part de chaque type de fichier (vidéos, images, documents…).

## Télécharger

Va dans l'onglet **Releases** et télécharge `Spaceo.exe`
(ou `Spaceo-Windows7.exe` pour un vieux PC).

## Utilisation

Double-clique sur l'exe, choisis le disque, clique sur « Analyser mon disque ».
